Place the clinician-approved full guide content here, outside `public/`.
Each file must be named after its catalogue ID, for example `desk-guide.json`.
Use this structure, with one entry for EVERY module listed in `catalog.json`:

```json
{
  "modules": [
    {
      "title": "Understanding desk-related pain",
      "paragraphs": ["Full clinician-approved text goes here."]
    }
  ]
}
```

The example shows the format only. The desk guide requires six modules.
Missing, malformed, or incomplete books cannot be purchased. Do not publish
placeholder treatment content. Content is returned as plain text only after
server-side payment verification. Put images/PDFs in private storage with
authorized delivery if the final books need those formats; this reader serves
text modules and does not currently provide PDF downloads.
